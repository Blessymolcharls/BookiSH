# Contributing to BookiSH

Thanks for your interest in contributing! We welcome fixes, improvements, and new features.

How to contribute

1. Fork the repository.
2. Create a descriptive branch: `git checkout -b feature/short-description`.
3. Make focused, testable changes.
4. Commit with clear messages and push to your fork.
5. Open a Pull Request describing what you changed and why.

Guidelines

- Keep changes small and well-scoped.
- Include setup/run instructions for new server-side code.
- Follow the existing project structure and coding patterns.
- For significant changes, open an issue first to discuss the approach.

Code of Conduct

Be respectful and constructive.
